# 🔘 Make Cool Buttons

Design a CSS button in seconds: soft, 3D, glossy, neon, gradient or outline. Pick colors, then copy, download or save the code.

**▶ Use it here: [https://drew-traldi.github.io/make-cool-buttons/](https://drew-traldi.github.io/make-cool-buttons/)**

- Free, no sign-up, no ads
- Runs entirely in your browser. Nothing you enter is sent to a server.
- Works on desktop and mobile

## Run it locally

It's a single HTML file. Download `index.html` and open it in any modern browser.
